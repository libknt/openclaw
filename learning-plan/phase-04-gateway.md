# Phase 4: Gateway（コントロールプレーン）の理解

**前提フェーズ**: Phase 3
**状態**: :white_large_square: 未着手

## 目標

WebSocketベースのGatewayサーバーの全体アーキテクチャを理解する。

## チェック項目

### 4.1 全体構成
- [ ] `src/gateway/` ディレクトリのファイル一覧を確認し、モジュール構成を把握する
- [ ] Gateway の役割（セッション管理、メッセージルーティング、認証、Webhook処理）を理解する

### 4.2 初期化フロー
- [ ] `gateway/boot.ts` を読み、Gateway の起動シーケンスを理解する
- [ ] Express サーバーの設定（ミドルウェア、ルート定義）を確認する
- [ ] WebSocket サーバーの初期化を確認する

### 4.3 WebSocket プロトコル
- [ ] バイナリフレームフォーマットの定義を見つけ、プロトコル仕様を理解する
- [ ] メッセージタイプ（コマンド、応答、ストリーミング等）の一覧を確認する
- [ ] 接続のライフサイクル（接続→認証→メッセージ交換→切断）を追跡する

### 4.4 認証
- [ ] `gateway/auth.ts` を読み、認証フローを理解する
- [ ] デバイス認証（TLSフィンガープリンティング）の仕組みを確認する
- [ ] トークン管理の実装を確認する

### 4.5 セッション管理
- [ ] `gateway/client.ts` を読み、クライアント側のプロトコル実装を理解する
- [ ] プレゼンス追跡（オンライン/オフライン）の仕組みを確認する
- [ ] 自動再接続のロジックを確認する

### 4.6 Webhook処理
- [ ] Webhook 受信エンドポイントの実装を見つける
- [ ] Webhook ペイロードの検証・処理フローを追跡する

### 4.7 VoIP/通話
- [ ] `gateway/call.ts` を読み、音声通話機能の実装を確認する
