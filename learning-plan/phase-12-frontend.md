# Phase 12: Web UI とネイティブアプリの理解

**前提フェーズ**: Phase 4
**状態**: :white_large_square: 未着手

## 目標

フロントエンド（Web UI・macOS・iOS・Android）のアーキテクチャを理解する。

## チェック項目

### 12.1 Web UI の全体像
- [ ] `ui/` ディレクトリの構成を確認する
- [ ] `ui/package.json` を読み、依存関係（Lit.js, Vite）を確認する
- [ ] `ui/vite.config.ts` を読み、ビルド設定を確認する

### 12.2 Web UI のコンポーネント構成
- [ ] `ui/src/` のエントリポイントを確認する
- [ ] 主要な Web Components（Lit.js）の実装パターンを確認する
- [ ] ルーティング・状態管理の仕組みを確認する

### 12.3 Gateway との通信
- [ ] Web UI から Gateway への WebSocket 接続の実装を確認する
- [ ] リアルタイム更新（ストリーミング応答等）の処理を確認する
- [ ] 認証トークンの管理を確認する

### 12.4 macOS アプリ
- [ ] `apps/macos/` の構成を確認する
- [ ] SwiftUI によるメニューバーアプリの実装を確認する
- [ ] ネイティブ機能（通知、キーボードショートカット等）を確認する

### 12.5 iOS アプリ
- [ ] `apps/ios/` の構成を確認する
- [ ] iOS アプリのアーキテクチャ（画面遷移、データバインディング）を確認する

### 12.6 共有コード
- [ ] `apps/shared/` (OpenClawKit) を読み、ネイティブアプリ間の共有コードを確認する
- [ ] Swift Package Manager による依存関係管理を確認する
- [ ] 共有コードと各プラットフォーム固有コードの境界を理解する

### 12.7 Android アプリ
- [ ] `apps/android/` の構成を確認する（存在する場合）

## 完了条件

> 「フロントエンドがどのようにバックエンドと通信し、ユーザー体験を提供するか」を説明できる
