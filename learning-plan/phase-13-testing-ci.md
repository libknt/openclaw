# Phase 13: テスト・CI/CD・ビルドパイプラインの理解

**前提フェーズ**: Phase 1
**状態**: :white_large_square: 未着手

## 目標

テスト戦略、CI/CDパイプライン、リリースフローを理解する。

## チェック項目

### 13.1 テスト設定
- [ ] `vitest.config.ts`（ベース設定）を読む
- [ ] `vitest.unit.config.ts` を読み、ユニットテスト設定を確認する
- [ ] `vitest.e2e.config.ts` を読み、E2E テスト設定を確認する
- [ ] `vitest.gateway.config.ts` を読み、Gateway テスト設定を確認する
- [ ] `vitest.extensions.config.ts` を読み、拡張テスト設定を確認する
- [ ] `vitest.live.config.ts` を読み、ライブテスト設定を確認する
- [ ] 各設定間の違い（テスト対象、タイムアウト、並列度等）を理解する

### 13.2 テストパターン
- [ ] ユニットテストのサンプルを2-3本読み、テストの書き方を理解する
- [ ] E2E テストのサンプルを読み、統合テストのパターンを理解する
- [ ] モック・スタブの使い方を確認する
- [ ] テストカバレッジの閾値（70% lines/functions/statements, 55% branches）を確認する

### 13.3 リンティング・フォーマット
- [ ] `.oxlintrc.json` を読み、Oxlint のルール設定を確認する
- [ ] `pnpm check` の実行内容（lint + format check）を確認する

### 13.4 CI/CD パイプライン
- [ ] `.github/workflows/` の主要ワークフローを確認する
- [ ] CI パイプラインの全体フロー（テスト→ビルド→リリース）を理解する
- [ ] プルリクエスト時に実行されるチェックを確認する

### 13.5 Docker 化
- [ ] `Dockerfile` を読み、プロダクション用イメージの構成を理解する
- [ ] `docker-compose.yml` を読み、ローカル開発用サービスを確認する
- [ ] `Dockerfile.sandbox*` を読み、サンドボックス環境の構成を確認する

### 13.6 ビルドスクリプト
- [ ] `scripts/` ディレクトリの主要スクリプトを確認する
- [ ] ビルドヘルパー（`build-*.ts`）の役割を理解する
- [ ] テストランナー（`test-*.sh`）の役割を理解する

### 13.7 リリースフロー
- [ ] バージョニング規則（`vYYYY.M.D` or `vYYYY.M.D-beta.N`）を確認する
- [ ] リリースチャンネル（stable/beta/dev）の管理方法を理解する
- [ ] npm パッケージの公開フローを確認する
- [ ] macOS アプリのパッケージング（`package-mac-app.sh`）を確認する

## 完了条件

> 「コードがどのようにテスト・ビルド・リリースされるか」を説明できる
