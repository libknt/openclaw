# Phase 7: プラグインシステムとフックの理解

**前提フェーズ**: Phase 5
**状態**: :white_large_square: 未着手

## 目標

プラグインの発見・登録・フックによる拡張の仕組みを理解する。

## チェック項目

### 7.1 プラグインの発見とロード
- [ ] `src/plugins/` ディレクトリの全体構成を確認する
- [ ] プラグイン発見の仕組み（npm レジストリ + ローカルワークスペース）を理解する
- [ ] プラグインのロード・初期化フローを追跡する
- [ ] プラグインの依存関係解決の仕組みを確認する

### 7.2 プラグイン SDK
- [ ] `src/plugin-sdk/` を読み、パブリック API の設計を理解する
- [ ] プラグインが利用可能なメソッド・イベント・型定義を把握する
- [ ] プラグイン開発者が従うべきインターフェースを理解する

### 7.3 フックシステム
- [ ] `src/hooks/` ディレクトリの全体構成を確認する
- [ ] フックの種類（before-start, phase hooks, model overrides 等）を把握する
- [ ] フックの登録・実行順序・優先度の仕組みを理解する
- [ ] フックによる本体動作のカスタマイズ例を確認する

### 7.4 プラグインの種類
- [ ] Channel プラグインの実装パターンを確認する
- [ ] Memory プラグインの実装パターンを確認する
- [ ] Auth プロバイダプラグインの実装パターンを確認する
- [ ] Custom Tools プラグインの実装パターンを確認する

### 7.5 具体的なプラグイン実装の確認
- [ ] `extensions/` から1つプラグインを選び、実装の全体像を読む
- [ ] `package.json` のプラグインメタデータ（エントリポイント、依存関係）を確認する
- [ ] プラグインのテストパターンを確認する

## 完了条件

> 「プラグインがどのように発見・ロード・実行され、本体の動作をカスタマイズできるか」を説明できる
