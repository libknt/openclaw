# Phase 3: 設定システム（Config）の理解

**前提フェーズ**: Phase 2
**状態**: :white_large_square: 未着手

## 目標

設定ファイルの読み込み・バリデーション・ホットリロードの仕組みを理解する。

## チェック項目

### 3.1 設定スキーマ
- [ ] `src/config/` ディレクトリの全体構成を確認する
- [ ] Zod による設定スキーマの定義を見つけ、全体構造を把握する
- [ ] `openclaw.json` の主要セクション（gateway, agents, channels, memory, models, session）のスキーマを確認する

### 3.2 設定の読み込みフロー
- [ ] 設定ファイルの検索パス（`~/.openclaw/openclaw.json` 等）を確認する
- [ ] ファイル読み込み → YAML/JSONパース → Zodバリデーション → マージの流れを追跡する
- [ ] デフォルト値の設定方法を理解する

### 3.3 環境変数との統合
- [ ] `.env` ファイルや環境変数がどのように設定に反映されるかを確認する
- [ ] 環境変数と設定ファイルの優先順位を理解する

### 3.4 ホットリロード
- [ ] `src/gateway/config-reload.ts` を読み、設定の動的更新の仕組みを理解する
- [ ] どの設定項目がホットリロード可能で、どれが再起動を必要とするかを確認する

### 3.5 設定のバリデーションとエラーハンドリング
- [ ] 不正な設定値が与えられた場合のエラー処理を確認する
- [ ] `openclaw doctor` による設定診断の仕組みを確認する

## 完了条件

> 「設定がどのように定義・読み込み・検証・更新されるか」を説明できる
