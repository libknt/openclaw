# Phase 10: セキュリティモデルの理解

**前提フェーズ**: Phase 5
**状態**: :white_large_square: 未着手

## 目標

セキュリティ設計全体（認証・認可・隔離）を理解する。

## チェック項目

### 10.1 セキュリティの全体像
- [ ] `src/security/` ディレクトリの全体構成を確認する
- [ ] `SECURITY.md` を読み、セキュリティポリシーを把握する
- [ ] セキュリティに関わるモジュール間の関係を把握する

### 10.2 DM ペアリング
- [ ] 未知の送信者からのDMの隔離フローを追跡する
- [ ] ペアリング承認のプロセス（CLI経由 or 設定ファイル）を確認する
- [ ] ペアリング情報の永続化方法を確認する

### 10.3 Allowlist マッチング
- [ ] Allowlist の定義方法（設定ファイル内の書式）を確認する
- [ ] マッチングアルゴリズム（ユーザーID、グループ、パターン等）の実装を確認する
- [ ] Allowlist の評価タイミング（どの段階でチェックされるか）を確認する

### 10.4 コマンドゲーティング
- [ ] チャンネル別の権限制御の実装を確認する
- [ ] ユーザー別の権限制御の実装を確認する
- [ ] 権限不足時のエラーハンドリングを確認する

### 10.5 デバイス認証
- [ ] TLSフィンガープリンティングの実装を確認する
- [ ] デバイスIDの生成・管理の仕組みを確認する
- [ ] Gateway 認証との統合を確認する

### 10.6 入力の安全性
- [ ] 信頼できない入力に対するサニタイズ処理を確認する
- [ ] セーフデフォルト（デフォルトで安全な設定）の設計を確認する

## 完了条件

> 「このシステムがどのようにユーザーを認証し、不正アクセスを防止するか」を説明できる
